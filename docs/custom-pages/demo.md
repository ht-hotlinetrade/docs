# Кастом страницы > Демо / гайд по использованию

### ℹ️ Что это такое

Кастомные страницы — это ваши собственные страницы внутри магазина: правила сервера, FAQ, описание привилегий, контакты, вайп-лист и т.д. Страница открывается по своему адресу, например `https://ваш-домен/rules`, и выглядит как часть сайта (с шапкой, меню и подвалом магазина).

---

### ⚙️ Создание страницы

1. Переходим в **Управление → Страницы** и нажимаем **«Создать»**.
2. Заполняем вкладку **«Основное»**:

| Поле | Описание |
|---|---|
| **Title** | Заголовок страницы. Можно указать переводы на другие языки сайта |
| **Route** | Адрес страницы без домена и начального `/`. Например `rules` → `https://ваш-домен/rules`. Допустимы латиница, цифры, `-`, `_` и вложенность через `/` (например `info/rules`). Адрес должен быть уникальным и не может совпадать с системными адресами магазина (`profile`, `admin` и т.п.) |
| **Description** | Описание страницы (используется для поисковиков и превью ссылки) |
| **Добавить ссылку в верхнее меню** | Если включено — в разделе «Ссылки» автоматически создастся пункт меню на эту страницу. Доступно только при создании |
| **Is auth only** | Если включено — страницу увидят только авторизованные пользователи, остальные получат ошибку 403 |

3. Во вкладке **HTML** пишем содержимое страницы. Для каждого языка сайта можно задать свой вариант HTML.
4. При необходимости заполняем вкладки **CSS** и **JS**.
5. Нажимаем **«Создать»**.

---

### 🧩 Вкладки HTML / CSS / JS

* **HTML** — разметка страницы. Вставляется внутрь страницы магазина, поэтому `<html>`, `<head>` и `<body>` писать не нужно.
* **CSS** — стили. Код вставляется в тег `<style>` только на этой странице и не влияет на остальной сайт.
* **JS** — скрипты. Код вставляется в тег `<script>` и выполняется после отрисовки страницы.

::: tip
Чтобы стили не задели остальные элементы сайта, оборачивайте содержимое в свой блок с уникальным классом и пишите стили через него, как в примере ниже.
:::

---

### 📄 Пример: страница правил

**HTML**
```html
<div class="rules-page">
  <h1>Правила сервера</h1>

  <div class="rules-block">
    <h2>1. Общие положения</h2>
    <p>Заходя на сервер, вы соглашаетесь с правилами.</p>
  </div>

  <div class="rules-block">
    <h2>2. Запрещено</h2>
    <ul>
      <li>Использование читов и сторонних программ</li>
      <li>Использование багов игры</li>
      <li>Оскорбления игроков и администрации</li>
    </ul>
  </div>

  <button class="rules-accept">Я прочитал правила</button>
</div>
```

**CSS**
```css
.rules-page {
  max-width: 900px;
  margin: 0 auto;
  padding: 24px;
}

.rules-block {
  margin-bottom: 16px;
  padding: 16px;
  border-radius: 8px;
  background: rgba(255, 255, 255, 0.05);
}

.rules-accept {
  padding: 10px 20px;
  border-radius: 6px;
  background: #26a69a;
  color: #fff;
}
```

**JS**
```js
document.querySelector('.rules-accept')?.addEventListener('click', () => {
  alert('Спасибо! Приятной игры.');
});
```

---

### 🔗 Ссылка в меню

Если при создании вы не включили **«Добавить ссылку в верхнее меню»**, ссылку можно добавить вручную: **Управление → Ссылки → Создать**, в поле **URL** укажите адрес страницы (например `/rules`).

Подробнее про работу со скриптами — на странице [Важно перед началом использования (JS)](/docs/custom-editor/js/important-before-start).
