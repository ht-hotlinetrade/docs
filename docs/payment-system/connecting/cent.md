# 💳 Cent — подключение платёжной системы
::: info
Если оплата не проходит, проверьте:

* корректность URL уведомлений (Result URL)
* правильность Shop ID и API Token
* что код верификации указан в магазине и проект подтверждён в Cent
* что проект активирован и способы оплаты включены
:::
---

### ⚙️ Настройка Cent

#### 1️⃣ Регистрация и вход в кабинет

Перейдите на страницу регистрации ([Cent.app](https://cent.app/?r=p5136_ht)) и создайте аккаунт.
После регистрации войдите в **личный кабинет**.

---

#### 2️⃣ Создание проекта

В личном кабинете откройте меню:

**«Проекты» → «Добавить проект»**

---

#### 3️⃣ Заполнение данных проекта

* **URL сайта, Success URL, Fail URL** — ссылка на ваш магазин (например `https://demo.hotlinetrade.net`)
* **Result URL** — оранжевая ссылка из блока **Cent** в магазине: **Управление → Настройки → Платежные настройки** (например `https://demo.hotlinetrade.net/api/payments/cent/callback`)
* **Описание** — подробно опишите, чем занимается ваш сайт

---

#### 4️⃣ Верификация сайта

Для подтверждения владения сайтом:

1. Выберите способ
   ☑ **Подтверждение с помощью текстового файла**

2. Скопируйте код, указанный в кавычках, или название файла (см. скрин, выделено)
![](/images/payment-system/connecting/paypalych/verif.png)

3. Вставьте его в поле **«Код верификации»** в магазине (пункт 6️⃣). Можно вставлять как сам код, так и полное имя файла `shop-verification-XXXX.txt` — магазин сам обрежет лишнее.

4. Сохраните настройки магазина и только после этого нажмите **«Проверить»** в Cent. Магазин автоматически отдаёт файл по адресу `https://ваш-домен/shop-verification-XXXX.txt` — создавать его вручную не нужно.

---

#### 5️⃣ Получение API-данных

В настройках проекта Cent скопируйте:

* 🆔 **Shop ID**
* 🔑 **API Token**

---

#### 6️⃣ Ввод данных в магазине

Перейдите в **Управление → Настройки → Платежные настройки**, раскройте блок **Cent** и заполните:

| Поле в магазине | Что вставить |
|---|---|
| ВКЛ / ВЫКЛ Платежную систему | Включить |
| Комиссию платит пользователь | По желанию: если включено, комиссия Cent добавляется к сумме платежа игрока |
| ID магазина | Shop ID из пункта 5️⃣ |
| API Ключ | API Token из пункта 5️⃣ |
| Описание платежа | Необязательно. По умолчанию — «Пополнение баланса» |
| Код верификации | Код из пункта 4️⃣ |

Нажмите **«Сохранить»**.

---

### ✅ Готово

Cent подключён и готов принимать платежи. Общие параметры (минимальная сумма, логотип, бонусы к пополнению) описаны на странице [Общие настройки ПС](/docs/payment-system/other/general-settings).
