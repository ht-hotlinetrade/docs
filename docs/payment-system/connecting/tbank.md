# 💳 Tbank — подключение платёжной системы
::: info
Если оплата не проходит, проверьте:

* что ссылка на уведомления указана **на обоих терминалах** (тестовом и боевом)
* что в магазине указан **боевой** терминал, а не тестовый (DEMO)
* правильность Terminal ID и пароля терминала
:::
---

### ⚙️ Настройка Tbank

#### 1️⃣ Регистрация и вход в кабинет

Перейдите на страницу регистрации Tbank (https://business.tbank.ru), зарегистрируйтесь и заведите интернет-эквайринг (кассу).
После регистрации войдите в **личный кабинет**.

---

#### 2️⃣ Настройка уведомлений (обязательно)

Скриншот, откуда необходимо брать ссылку на уведомления (блок **ТБанк** в **Управление → Настройки → Платежные настройки**, оранжевая ссылка)
![](/images/payment-system/connecting/tbank/url.png)

Необходимо указать эту ссылку в поле "Уведомления" - "По протоколу HTTP" на основной и тестовой кассе
![](/images/payment-system/connecting/tbank/pre-url.png)
![](/images/payment-system/connecting/tbank/post-url.png)

Вставляем url, нажимаем "Сохранить". Это обязательно сделать для обоих терминалов! И для демо, и для основного!!!

---

#### 3️⃣ Получение данных терминала

В личном кабинете Т-Бизнес откройте **Интернет-эквайринг → Магазины → ваш магазин → Терминалы** и скопируйте у **боевого** терминала:

* 🆔 **Terminal Key** (ID терминала)
* 🔑 **Пароль** терминала

---

#### 4️⃣ Ввод данных в магазине

Перейдите в **Управление → Настройки → Платежные настройки**, раскройте блок **ТБанк** и заполните:

| Поле в магазине | Что вставить |
|---|---|
| ВКЛ / ВЫКЛ Платежную систему | Включить |
| Tbank terminal id | Terminal Key из пункта 3️⃣ |
| Tbank terminal key | Пароль терминала из пункта 3️⃣ |
| Tbank taxication email | Email, на который будут уходить чеки (если подключена онлайн-касса) |
| Система налогообложения | Ваша система налогообложения (Общая, УСН доход и т.д.) |
| Тип НДС | Обязательное поле. Если вы не плательщик НДС — «НДС отсутствует» |

Нажмите **«Сохранить»**.

::: tip
Система налогообложения, тип НДС и email используются для формирования чека (54-ФЗ). Если онлайн-касса у вас не подключена — оставьте налогообложение пустым, а НДС выставьте «НДС отсутствует».
:::

---

### ✅ Готово

Tbank успешно подключён и готов принимать платежи.
