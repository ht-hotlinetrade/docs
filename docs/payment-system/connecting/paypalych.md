# 💳 PayPalych — подключение платёжной системы
::: info
Если оплата не проходит, проверьте:

* корректность URL уведомлений
* правильность Shop ID и Token
* что касса активирована
* что способы оплат включены
:::
---

### ⚙️ Настройка PayPalych

#### 1️⃣ Регистрация и вход в кабинет

Перейдите на страницу регистрации PayPalych (pally.info) и создайте аккаунт.
После регистрации войдите в **личный кабинет**.

---

#### 2️⃣ Создание магазина

В личном кабинете откройте меню:

**«Магазины» → «Добавить магазин»**

---

#### 3️⃣ Заполнение данных магазина

Заполните форму создания магазина.

Вид деятельности - IT Телеком
Описание магазина - Тут полностью описываете чем занимается ваш сайт  
URL Магазина, SUCCESS URL, FAIL URL - ссылка на ваш магазин (например https://demo.hotlinetrade.net)  
Result URL - оранжевая ссылка из настроек в магазине в блока PayPalych (например https://demo.hotlinetrade.net/api/payments/paypalych/callback) (см. скрин)

Скриншот откуда брать RESULT URL
![](https://i.postimg.cc/2yShPgxn/image.png)

---

#### 4️⃣ Верификация сайта

Для подтверждения владения сайтом:

1. Выберите способ
   ☑ **Подтверждение с помощью текстового файла**

2. Копируем код что указан в кавычках, или названеи файла (см скрин, выделено)
![](/images/payment-system/connecting/paypalych/verif.png)

3. Этот код вставляем в поле "Код верификации" в 7️⃣ пункте
---

#### 5️⃣ Активация кассы

Перейдите в раздел: **«Основные настройки» кассы** и включите параметр:

☑ **Активен** (см. скрин)
![](https://i.postimg.cc/XNrwk6pb/image.png)

---

#### 6️⃣ Получение API-данных

Откройте:

**Настройки кассы → API интеграция**

Скопируйте:

* 🆔 **Shop ID**
* 🔑 **API Token**

---

#### 7️⃣ Ввод данных в магазине

В админ-панели сайта в разделе PayPalych вставьте:

* Shop ID — в поле Paypalych shop id
* Token — в поле Paypalych api key
* Код верификацуии - код скопированный из 4️⃣ пункта

![](https://i.postimg.cc/qMtCysbP/image.png)

Сохраните настройки.

#### 8️⃣ Добавляем IP сайта в WhiteList

В админ-панели переходим во вкладку "API интеграция":

* Нажимаем WhiteList
* Нажимаем добавить
* Указываем IP из https://docs.hotlinetrade.net/docs/product/webhook/additional-info.html
* Нажимаем "Обновить"
![](/images/payment-system/connecting/paypalych/ip.jpg)
---

### ✅ Готово

PayPalych успешно подключён и готов принимать платежи.
