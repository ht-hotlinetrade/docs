# 💳 Остальные платёжные системы

На этой странице кратко описано, какие данные нужны для ПС, у которых пока нет отдельной инструкции. Для всех ПС действует общий порядок:

1. Зарегистрируйтесь в платёжной системе и создайте магазин/кассу.
2. В магазине откройте **Управление → Настройки → Платежные настройки** и раскройте блок нужной ПС.
3. Скопируйте **оранжевую ссылку** внизу блока и укажите её в кабинете ПС как адрес для уведомлений (Result URL / Callback URL / URL оповещения).
4. Перенесите ключи из кабинета ПС в поля магазина (таблицы ниже), включите ПС и сохраните.

Общие поля (минимальная сумма, логотип, бонусы) описаны на странице [Общие настройки ПС](/docs/payment-system/other/general-settings).

::: tip
Адрес для уведомлений всегда имеет вид `https://ваш-домен/api/payments/{пс}/callback`. Если в кабинете ПС есть выбор метода — выбирайте **POST**.
:::

---

### Енот (enot.io)

| Поле в магазине | Где взять |
|---|---|
| ID магазина | ID кассы в кабинете Енот |
| Секретный ключ | Секретный ключ кассы |
| Второй секретный ключ | Дополнительный ключ (используется для проверки уведомлений) |

---

### Robokassa (robokassa.com)

| Поле в магазине | Где взять |
|---|---|
| ID магазина | Идентификатор магазина (MerchantLogin) |
| Секретный ключ | Пароль #1 |
| Второй секретный ключ | Пароль #2 |
| Система налогообложения | Если подключена фискализация (чеки) |

В кабинете Robokassa в поле **Result URL** укажите оранжевую ссылку, метод — POST.

---

### UnitPay (unitpay.ru)

| Поле в магазине | Где взять |
|---|---|
| Публичный ключ | Публичный ключ проекта |
| Секретный ключ | Секретный ключ проекта |

---

### CloudPayments (cloudpayments.ru)

| Поле в магазине | Где взять |
|---|---|
| Публичный ключ | Public ID |
| Секретный ключ | Пароль для API |
| ИНН Компании | ИНН вашей организации / ИП |
| Система налогообложения | Обязательно при включённой ПС |
| Тип НДС | Обязательно при включённой ПС |

---

### PayPal (paypal.com)

| Поле в магазине | Где взять |
|---|---|
| Paypal client id | Client ID приложения в PayPal Developer |
| Paypal client secret | Secret приложения |
| Коэффициент конвертации USD → RUB | Сколько рублей баланса начислять за 1 $. Например, при значении `90` оплата 10 $ даст 900 ₽ на баланс |

Минимальная сумма у PayPal может быть от 1 ₽.

### ВТБ (vtb.ru)

|---|---|
| Логин API (userName) | Логин API-пользователя интернет-эквайринга ВТБ |
| Пароль API | Пароль API-пользователя |

### Tome (tome.ru)

| Поле в магазине | Где взять |
|---|---|
| ID магазина | ID магазина в кабинете Tome |
| Секретный ключ | Секретный ключ магазина |

---

### СБП / Карта Касса ИИ (kassa.ai)

Это дочерние способы оплаты **FREEKASSA** — они находятся внутри блока FREEKASSA и используют её ключи. Сначала подключите [FREEKASSA](/docs/payment-system/connecting/freekassa), затем включите нужный способ (СБП или карта) и при желании задайте ему свою минимальную сумму, логотип и бонусы. Ссылка на уведомления у них общая с FREEKASSA.

::: info
Помимо секретных ключей, у FREEKASSA есть поле **API Ключ** — его можно взять в настройках кассы FREEKASSA (раздел API).
:::
