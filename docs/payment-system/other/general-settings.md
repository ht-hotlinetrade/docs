# ⚙️ Общие настройки платёжных систем

Все платёжные системы настраиваются в разделе **Управление → Настройки → Платежные настройки**. Каждая ПС — отдельный раскрывающийся блок. Внизу каждого блока оранжевым выделена **ссылка на обработчик уведомлений** (callback) — её указывают в кабинете платёжной системы.

Формат ссылки одинаковый для всех ПС:

```
https://ваш-домен/api/payments/{платёжная_система}/callback
```

---

### 🧩 Поля, которые есть у каждой ПС

| Поле | Описание |
|---|---|
| **ВКЛ / ВЫКЛ Платежную систему** | Показывать ли ПС в окне пополнения. Пока ПС выключена, её обязательные поля можно не заполнять |
| **Минимальная сумма платежа** | Меньше этой суммы игрок пополнить не сможет. Нельзя указать меньше 10 ₽ (у PayPal — 1 ₽) |
| **Логотип** | Своя картинка для ПС в окне пополнения. Если не заполнено — используется стандартный логотип |
| **Бонус к пополнению** | Таблица «Бонус (%) / Мин сумма (₽)». Если игрок пополняет на сумму не меньше «Мин суммы», ему начисляется дополнительный процент. Можно добавить несколько ступеней, например 5% от 500 ₽ и 10% от 1000 ₽ — применяется одна, самая высокая достигнутая ступень (бонусы не суммируются) |

---

### 🔀 Порядок и ПС по умолчанию

* **Порядок платежных систем** — перетащите ПС, чтобы изменить их порядок в окне пополнения.
* **Платежная система по умолчанию** — эта ПС будет выбрана автоматически, когда игрок открывает окно пополнения.

---

### 🔄 Статусы платежей

Все платежи видны в разделе **История → Платежи**.

| Статус | Значение |
|---|---|
| Ожидается | Платёж создан, ПС ещё не прислала подтверждение |
| Выполнено | Деньги поступили, баланс начислен |
| Отменен | Платёж отменён или не был оплачен |
| Возвращено | Платёж возвращён |

Раз в 6 часов магазин сам перепроверяет зависшие платежи в статусе «Ожидается». Если ПС так и не прислала уведомление, платёж можно [засчитать вручную](/docs/payment-system/other/submit-payment).

### 🛡️ IP-адреса магазина
