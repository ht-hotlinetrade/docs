# Интеграции > Нейросети (MCP)

::: info
Раздел доступен только на тарифах с поддержкой MCP. Если пункта **Инструменты → Нейросети (MCP)** нет в меню — функция не входит в ваш тариф или у вашей роли нет права на неё.
:::

### ℹ️ Что это такое

**MCP (Model Context Protocol)** — стандарт, по которому нейросети (Claude, ChatGPT, Cursor и другие) подключаются к внешним системам. Подключив магазин, вы управляете им обычным текстом, а нейросеть сама вызывает нужные действия админки.

Примеры запросов:
* «Покажи статистику за неделю»
* «Найди игрока со Steam ID 7656… и покажи его последние покупки»
* «Начисли 100 ₽ пользователю X в качестве компенсации»
* «Скрой товар Y»
* «Создай страницу с правилами сервера и добавь её в меню»

---

### 1️⃣ Выпуск токена

1. Откройте **Инструменты → Нейросети (MCP)**.
2. В блоке **«MCP-токены»** нажмите **«Выпустить токен»**.
3. Заполните:
   - **Название** — чтобы потом понять, что это за токен (например «Claude на рабочем ноутбуке»)
   - **Только чтение** — нейросеть сможет только смотреть данные, без изменения балансов, банов, товаров и промокодов. **Для начала рекомендуется включить**
   - **Действует до** — пусто для бессрочного токена
4. **Сразу скопируйте токен** — он показывается только один раз. Если потеряли — выпустите новый.

---

### 2️⃣ Подключение нейросети

MCP-сервер работает по протоколу **Streamable HTTP**:

* **Адрес:** `https://ваш-домен/mcp/admin` (точный адрес показан на странице)
* **Авторизация:** заголовок `Authorization: Bearer ВАШ_ТОКЕН`

На странице **Нейросети (MCP)** есть готовые примеры конфигурации для Claude Desktop (`claude_desktop_config.json`, нужен Node.js) и Cursor (`mcp.json`). Подойдёт любой клиент, который поддерживает удалённые MCP-серверы по HTTP и позволяет задать заголовок Authorization.

### 3️⃣ Проверка

Попросите нейросеть: «покажи статистику магазина за сегодня». Она должна вызвать инструмент `get-shop-statistics` и вернуть данные.

---

### 🧰 Что умеет нейросеть

| Раздел | Действия |
|---|---|
| Статистика | Регистрации, пополнения, покупки, топ товаров за период |
| Пользователи | Поиск, карточка, изменение баланса, бан и разбан |
| Товары и категории | Просмотр, создание, изменение цены / видимости / сортировки, выдача товара игроку |
| Платежи и покупки | Просмотр с фильтрами |
| Промокоды | Просмотр, создание, изменение, включение / выключение, удаление |
| Кастомные страницы | Просмотр, создание, изменение, удаление |
| Уведомления | Каналы Telegram / Discord: подключение, изменение, удаление, тестовое сообщение |
| Журнал | Журнал действий администраторов |

Полный список инструментов с нужными правами — в блоке **«Инструменты и права»** на странице MCP.

---

### 🛡️ Безопасность

* Нейросеть действует **от вашего имени и с вашими правами** — не больше, чем вы можете сделать в админке.
* Доступ к MCP имеют роли с правом на страницу «Нейросети (MCP)» (настраивается в **Роли**). Набор инструментов зависит от остальных прав роли.
* Если у администратора снимут роль или право на MCP, все его токены сразу перестанут работать.
* Все изменения через MCP записываются в журнал действий с пометкой **(MCP)**.
* Перед изменением данных нейросеть должна описать действие и дождаться подтверждения — внимательно читайте, что она собирается сделать.
* У нейросети нет доступа к файлам, исходному коду, `.env`, базе данных напрямую и командам сервера.
* **Не публикуйте токен** — это ключ к вашему аккаунту администратора. Ненужные токены отзывайте кнопкой **«Отозвать»**.
