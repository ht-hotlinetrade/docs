# Интеграции > API магазина

### ℹ️ Что это такое

API позволяет вашим ботам, сайтам и скриптам работать с магазином напрямую: получать пользователей, платежи и покупки, менять баланс, выдавать товары, создавать промокоды и т.д.

Полная интерактивная документация со всеми методами, параметрами и примерами ответов доступна в самом магазине по адресу:

```
https://ваш-домен/api/docs
```

Ссылка на неё также есть в меню админки: **Прочее → API Документация**.

---

### 1️⃣ Создание API-ключа

1. Переходим в **Управление → API Ключи** и нажимаем **«Создать»**.
2. Заполняем поля:

| Поле | Описание |
|---|---|
| **Key** | Сам ключ. Нажмите «сгенерировать», чтобы получить надёжный случайный ключ |
| **Expires at** | Дата окончания действия. Пусто — бессрочно. За 3 дня до истечения в админке появится предупреждение |
| **Labels** | Метки для себя, например `discord-bot` |
| **IP-адреса** | С каких IP разрешены запросы с этим ключом. Укажите IP сервера, где работает ваш бот |

3. Сохраняем.

::: danger
API-ключ даёт доступ к балансам и данным пользователей. Никому его не передавайте и не публикуйте в открытых репозиториях. Всегда ограничивайте ключ по IP.
:::

---

### 2️⃣ Авторизация запросов

Ключ передаётся в заголовке `Authorization`:

```bash
curl https://ваш-домен/api/users \
  -H "Authorization: Bearer ВАШ_КЛЮЧ" \
  -H "Accept: application/json"
```

| Ответ | Причина |
|---|---|
| `401 API key missing` | Не передан заголовок Authorization |
| `403 Invalid or expired API key` | Ключ не найден или истёк |
| `403 Access denied from this IP` | Запрос пришёл с IP, которого нет в списке ключа |
| `429 Too Many Requests` | Превышен лимит — 75 запросов в минуту |

---

### 3️⃣ Основные методы

| Раздел | Что можно делать |
|---|---|
| **Пользователи** `/api/users` | Список, карточка, поиск ID по SteamID (`/api/users/{steam_id}/system-id`), установка / пополнение / списание баланса |
| **Товары** `/api/products` | Список, создание, удаление, **выдача товара** пользователю (`POST /api/products/{id}/delivery`) |
| **Платежи** `/api/payments` | Список, просмотр, **подтверждение платежа** (`PATCH /api/payments/{id}/approve`) |
| **Покупки** `/api/purchases` | История покупок |
| **Промокоды** `/api/promocodes` | Список, создание, удаление, история использований |
| **Аренда** `/api/product-assignments` | Список аренд, проверка, остановка |
| **Переводы** `/api/transfers` | История переводов между игроками |
| **Сервера, категории, баннеры, ссылки** | Получение списков и управление |

Точные параметры каждого метода смотрите в `https://ваш-домен/api/docs`.

::: tip
Все запросы через API записываются в лог магазина. Для каждого бота/сервиса лучше создавать отдельный ключ — так его проще отозвать.
:::
