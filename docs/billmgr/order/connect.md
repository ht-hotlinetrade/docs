# Подключение домена к IP

## 1. Копируем IP

(Товары / Услуги -> Автоматический донат)

1. Переходим на страницу с оформленным магазином.
2. Открываем инструкцию и копируем IP.
3. Если хотите, можно не переходить ни в инструкцию, ни на страницу магазина: эта инструкция также дублируется на почту после оформления заказа.

<img src="https://i.imgur.com/4LoTuZp.png" />

<img src="https://i.imgur.com/8TiZnsB.png" />

## 2. Делегируем домен на этот IP

1. Переходим в управление доменом у своего регистратора. В примере используется REG.RU.

<img src="https://i.imgur.com/bGrN2I7.png" />

2. Удаляем все записи, которые добавлены по умолчанию после оформления домена. Это можно пропустить, если вы понимаете, что и зачем делаете.
3. Добавляем A-запись для поддомена @ на скопированный ранее IP.

<img src="https://i.imgur.com/vXKxKao.png" />

<img src="https://i.imgur.com/aX7vAW9.png" />

4. Нажимаем "Готово". Когда запись применится, сайт станет доступен.
