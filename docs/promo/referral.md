# Акции > Реферальная система

### ℹ️ Как это работает

У каждого пользователя есть свой **реферальный код** и **реферальная ссылка** вида `https://ваш-домен/r/КОД` — они отображаются в профиле игрока, в разделе «Рефералы».

1. Новый игрок переходит по ссылке (или вводит код в поле промокода).
2. Он становится **рефералом** пригласившего и получает бонус (если настроен).
3. С **каждого** пополнения реферала пригласивший получает награду на баланс.

Если гость перешёл по ссылке и ещё не авторизован, код запоминается и активируется автоматически после входа.

---

### ⚙️ Настройка

**Управление → Настройки → Реферальная система**

| Поле | Описание |
|---|---|
| **Состояние (вкл/выкл)** | Включает систему и раздел «Рефералы» в профиле игроков |

#### Приглашённый пользователь

| Поле | Описание |
|---|---|
| **Окно активации кода** | Сколько часов после регистрации игрок может активировать реферальный код. `0` — без ограничения |
| **Бонус приглашённому (промокод-шаблон)** | Промокод, награда из которого выдаётся рефералу при активации кода. Ограничения промокода (лимиты, даты) при этом не проверяются, поэтому сам промокод можно выключить, чтобы его не вводили напрямую. Если это промокод на пополнение — бонус начислится при первом подходящем пополнении |
| **Запретить активацию с IP пригласившего** | Нельзя активировать код с того же IP, что у пригласившего. Защита от «приглашения самого себя» со второго аккаунта |

#### Пригласивший пользователь

| Поле | Описание |
|---|---|
| **Тип награды по умолчанию** | **Фиксированная сумма** с каждого пополнения или **Процент от пополнения** |
| **Размер награды по умолчанию** | Сумма или процент |

---

### 🎥 Индивидуальные условия (блогеры)

Для отдельного пользователя можно задать свои условия: **Управление → Пользователи → редактирование → блок «Реферальная система»**:

| Поле | Описание |
|---|---|
| **Реферальный код** | Свой код, например `STREAMER` — тогда ссылка будет `https://ваш-домен/r/STREAMER`. Код не может совпадать с существующим промокодом |
| **Тип награды** / **Размер награды** | Переопределяют значения по умолчанию из настроек. Например, блогеру 15% вместо стандартных 5% |
| **Заметка** | Условия договорённости — видны только администрации |

---

### 🚫 Когда код не активируется

* реферальная система выключена;
* игрок вводит свой собственный код или код своего же реферала;
* у игрока уже есть пригласивший;
* истекло окно активации после регистрации;
* игрок уже пополнял баланс (активировать код можно только до первого пополнения);
* включена защита по IP и IP совпадает с IP пригласившего.

---

### 📊 История

Все приглашения и начисленные награды — в разделе **История → Рефералы**, а также во вкладке «Рефералы» в карточке пользователя.
