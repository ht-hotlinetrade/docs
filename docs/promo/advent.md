# Акции > Адвент-календарь

### ℹ️ Что это такое

Адвент-календарь — ежедневные награды для игроков в течение акции (например, с 1 по 31 декабря). Каждый день открывается новая «ячейка» с наградой: деньги на баланс или товар. Игроки забирают награды на отдельной странице календаря на сайте.

---

### ⚙️ Создание календаря

**Управление → Адвент-календари → «Создать»**

#### Вкладка «Основное»

| Поле | Описание |
|---|---|
| **Заголовок** / **Описание** | Название и описание акции (поддерживаются переводы) |
| **Дата начала** / **Дата конца** | Период акции |
| **Is active** | Включить / выключить календарь |
| **Запретить получение пропущенных дней** | Если включено — награду можно забрать только в день её открытия (кроме дней, где это отдельно разрешено) |
| **Скрывать награды до открытия дня** | До открытия дня игроки не видят, что в нём лежит |

#### Вкладка «Дни календаря»

Нажимайте **«Добавить день»** и заполняйте:

| Поле | Описание |
|---|---|
| **День** | Номер дня (1, 2, 3…) |
| **Дата разблокировки** | Необязательно. Если не указана — считается автоматически: дата начала + (день − 1) |
| **Описание дня** | Текст для игрока |
| **Разрешить забирать пропущенные дни** | Исключение из запрета пропущенных дней для этого дня |
| **Показывать награду заранее** | Показать награду до открытия, даже если в календаре включено скрытие |
| **Тип награды** | **Баланс** (сумма на баланс) или **Товар** |

#### Вкладка «Правила участия»

| Поле | Описание |
|---|---|
| **Мин. кол-во дней с момента регистрации** | Защита от новых «твинков»: участвовать могут только аккаунты старше N дней |
| **Мин. сумма всех пополнений пользователя** | Участвовать могут только игроки, пополнившие в сумме не меньше указанного |
