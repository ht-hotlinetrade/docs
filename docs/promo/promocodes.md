# Акции > Промокоды

Промокоды создаются в **Управление → Промокоды → «Создать»**. Игрок вводит промокод в профиле, а промокоды на пополнение — в окне пополнения баланса.

---

### 1️⃣ Типы промокодов

Тип выбирается во вкладке **«Наполнение промокода»**.

| Тип | Что получает игрок |
|---|---|
| **Сумма на баланс** | Фиксированная сумма сразу на баланс. Например, +100 ₽ |
| **Процент от баланса на баланс** | Процент от текущего баланса. Например, 10% при балансе 500 ₽ = +50 ₽ |
| **Сумма на баланс при пополнение** | Фиксированный бонус, который начислится при следующем пополнении. Можно указать минимальную сумму пополнения |
| **Процент на баланс при пополнение** | Бонус в процентах от суммы пополнения. Например, +15% к пополнению. Можно указать минимальную сумму пополнения |
| **Товар** | Бесплатная выдача товара на сервер |

---

### 2️⃣ Основные настройки

| Поле | Описание |
|---|---|
| **Код** | Текст промокода. Можно нажать «сгенерировать» для случайного кода. Код не может совпадать с чьим-то реферальным кодом |
| **Максимальное кол-во использований** | Сколько раз промокод можно использовать **всем** пользователям суммарно |
| **Максимальное кол-во использований одним человеком** | Сколько раз его может использовать один пользователь |
| **Задержка перед повторным использованием** | Через сколько минут один пользователь может снова ввести код (если разрешено несколько использований) |
| **Мин кол-во пополнений(раз)** | Промокод доступен только тем, кто пополнял баланс не меньше N раз. Защита от «твинков» |
| **Мин / Макс кол-во дней после регистрации** | Промокод доступен только аккаунтам нужного «возраста». Например, «макс 3 дня» — промокод только для новичков |
| **Несовместимые промокоды** | Эти промокоды нельзя использовать вместе с данным |
| **Дата начала / окончания действия** | Промокод активен только в этом промежутке |
| **Is active** | Быстро включить / выключить промокод |
| **Сервера** | Для промокода на товар: на каких серверах можно его получить. Если не выбрано — на всех текущих |

---

### 📊 Статистика

* **История → Использование промокодов** — кто и когда активировал промокоды.
* **Инструменты → Статистика по промокодам (донаты)** (если раздел доступен) — сколько задонатили игроки, которые ввели определённый промокод (удобно для оценки блогеров и партнёров).

::: tip
Для блогеров и партнёров удобнее использовать [реферальную систему](/docs/promo/referral): у каждого блогера свой код и своя награда с пополнений приглашённых игроков.
:::
