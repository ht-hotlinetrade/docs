# Настройки > Дизайн, баннеры и ссылки

## 🎨 Готовые шаблоны

**Дизайн → Готовые шаблоны** — быстрый способ сменить внешний вид магазина.

| Шаблон | Описание |
|---|---|
| Style 1 | Тёмно-белый дизайн, минималистичный и компактный |
| Style 2 | Дизайн в тёмных тонах с элементами зелёного |
| Style 3 | Классический сталкерский дизайн с тёмной цветовой схемой |
| Style 4 | Тёмная тема в стиле современного дизайна |
| Style 5 | Светлая тема в стиле современного дизайна |
| Style 6 | Тактическая витрина в духе рейдов и полевого снаряжения |

При нажатии **«Применить»** откроется окно: для каждого изображения (фон, шапка, фон карточки товара) и повтора фона можно выбрать — **взять из шаблона** или **оставить текущее**. Так можно сменить шаблон, не потеряв свои картинки.

## 🖼️ Дизайнерские настройки

**Управление → Настройки → Дизайн**

| Поле | Описание |
|---|---|
| **Изображение баннера** | Баннер (шапка) на главной странице |
| **Изображение на заднем фоне сайта** | Фон всего сайта. Галочка «зациклено» — фон повторяется плиткой (хорошо для текстур 64×64) |
| **Изображение на карточке товара** | Фон верхней части карточки товара, тоже можно зациклить |
| **Изображение логотипа бренда** | Логотип в шапке сайта вместо текстового названия |
| **Включить снег / гирлянду** | Новогоднее оформление |
| **Летучие мыши / тыквенная гирлянда** | Оформление на Хеллоуин |

Для более тонкой настройки используйте **Дизайн → Расширенный редактор** (CSS/JS) — см. разделы [CSS](/docs/custom-editor/css/which-block) и [JS](/docs/custom-editor/js/important-before-start). Расширенный редактор доступен не на всех тарифах.

## 📢 Баннеры

**Управление → Баннеры** — рекламные/информационные блоки на главной странице (акции, вайпы, новости).

| Поле | Описание |
|---|---|
| **Заголовок** / **Содержимое** | Текст баннера (Markdown, поддерживаются переводы) |
| **Цвет текста** / **Цвет фона** | Цвета баннера |
| **Изображение** | Картинка JPG, PNG или WEBP до 4 MB |
| **Позиция** | Над мониторингом, под мониторингом или над сортировкой |
| **URL** / **Тип ссылки** | Куда ведёт клик по баннеру и открывать ли в новой вкладке |
| **Сортировка** | Порядок баннеров |
| **Только для авторизованных** | Баннер видят только вошедшие игроки |
| **Скрыт** | Временно скрыть баннер, не удаляя |

## 🔗 Ссылки (меню)

**Управление → Ссылки** — пункты верхнего меню сайта (Discord, VK, правила, кастомные страницы).

| Поле | Описание |
|---|---|
| **Заголовок** | Текст ссылки (поддерживаются переводы) |
| **URL** | Адрес. Для своей страницы — путь, например `/rules` |
| **Тип ссылки** | В новой или в текущей вкладке |
| **Формат отображения** | Иконка и название / Название и иконка / Только иконка |
| **Иконка (SVG)** | Необязательная SVG-иконка |
| **Сортировка** | Порядок в меню |
| **Только для авторизованных** | Ссылку видят только вошедшие игроки |

## 🏷️ Метки товаров

**Управление → Метки товаров** — цветные плашки на карточках («Хит», «Новинка», «-50%»). У метки есть название и цвет. Привязываются к товару во вкладке **«Дополнительные настройки → Метки»**.
