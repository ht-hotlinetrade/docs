# Настройки > Основные и дополнительные настройки сайта

## Основные

**Управление → Настройки → Основные**

| Поле | Описание |
|---|---|
| **Название сайта** | Отображается в шапке и во вкладке браузера |
| **Описание сайта** | Описание для поисковиков и превью ссылки |
| **Keywords сайта** | Ключевые слова для поисковиков |
| **FAVICON сайта** | Иконка во вкладке браузера |
| **Превью сайта** | Картинка, которая показывается при отправке ссылки на сайт (Discord, Telegram, VK) |
| **Тип авторизации** | **Только через Steam** — обычный вход через Steam. **Вход по Email и подтверждение через Steam** — игрок регистрируется по email и паролю и один раз привязывает Steam |

### Отображаемая валюта сайта

Можно показывать игрокам вместо рублей свою «игровую» валюту, например алмазы 💎. Укажите название валюты и её символ.

::: info
Это только отображение. Расчётная валюта остаётся рублём и конвертируется 1 к 1: 1 рубль = 1 алмаз. Пополнение на 100 ₽ даст игроку 100 алмазов.
:::

## Дополнительные

**Управление → Настройки → Дополнительные**

| Поле | Описание |
|---|---|
| **Стартовый баланс** | Сумма, которая начисляется пользователю после первого входа на сайт |
| **Товаров на главной странице по дефолту** | Сколько товаров загружается сразу. Остальные подгружаются при прокрутке. Рекомендуется не более 25 |
| **Обслуживание сайта (отключение)** | Закрывает сайт на техработы: доступ останется только у администрации. В поле ниже можно указать текст, который увидят игроки |

## Документы

**Управление → Документы** — пользовательское соглашение, оферта, политика конфиденциальности и т.п.

| Поле | Описание |
|---|---|
| **Name** | Название документа |
| **Attachments** | Файл документа |
| **Is auth only** | Документ видят только авторизованные |
| **Is required for payment** | Перед пополнением игрок должен согласиться с этим документом. Многие платёжные системы требуют наличие оферты на сайте |

---

## Категории

**Управление → Категории** — разделы товаров на главной странице. У категории есть название (с переводами), сортировка и **Сервера**: если сервер не выбран, категория показывается на всех серверах.
