### ℹ️ Как устроен доступ

Доступ к панели управления определяется **ролями**. Любой пользователь, у которого есть хотя бы одна роль, может зайти в админку. Что именно он там видит и может делать — зависит от прав (permissions) этой роли.

* **super_admin** — роль владельца, имеет доступ ко всему без ограничений.
* Остальные роли вы создаёте сами под задачи: модератор, поддержка, контент-менеджер и т.д.

---

### 1️⃣ Создание роли

1. Переходим в **Управление → Настройки → Роли** и нажимаем **«Создать»**.
2. Указываем название роли, например `support`.
3. Отмечаем галочками права. Права сгруппированы по разделам (Товары, Пользователи, Платежи и т.д.), для каждого раздела есть отдельные действия: просмотр, создание, изменение, удаление.
4. Нажимаем **«Создать»**.

::: tip
Выдавайте минимально необходимые права. Например, сотруднику поддержки обычно хватает просмотра пользователей, платежей и покупок — без права менять баланс и удалять записи.
:::

---

### 2️⃣ Назначение роли пользователю

1. Пользователь должен хотя бы один раз авторизоваться на сайте.
2. Переходим в **Управление → Пользователи** и открываем редактирование нужного пользователя (найти можно по имени, Steam ID или email).
3. В поле **Roles** выбираем одну или несколько ролей.
4. Сохраняем.

После этого у пользователя появится доступ в панель управления.

::: warning
Менять роли может только тот, у кого есть право на создание ролей. Чтобы забрать доступ к админке — просто уберите у пользователя все роли.
:::
