# Сервер > Параметры сервера в магазине

Сервера добавляются в **Управление → Сервера → «Создать»**. Подключение FTP подробно описано в инструкциях [Выделенный / Домашний](/docs/server/connecting/vds) и [На панели управления](/docs/server/connecting/panel). Ниже — описание всех вкладок.

---

### Основное

| Поле | Описание |
|---|---|
| **Название** | Название сервера, видно игрокам при выборе сервера |
| **Игровой порт** | Значение параметра `steamport` из `serverDZ.cfg` |
| **Query порт** | Значение параметра `steamqueryport` из `serverDZ.cfg` |
| **Включен мониторинг?** | Показывать онлайн сервера на главной странице магазина |

### Параметры FTP

| Поле | Описание |
|---|---|
| **Имя пользователя** / **Пароль** | Данные FTP-пользователя |
| **Порт** | Обычно `21` |
| **Путь до корневой папки** | Обычно `/` |
| **Путь до папки profiles начиная от корневой** | Обычно `profiles/` |
| **FTP Pasv** | Пассивный режим. В большинстве случаев — **выключен** |

### Параметры WARGM

Заполняется только если используется автовыдача с WARGM — см. [Подключение WARGM](/docs/product/wargm/connect).

### Дополнительные настройки

::: danger
Не трогайте эти параметры, если не понимаете, зачем они нужны.
:::

* **Использовать SSL для FTP-соединения (FTPS)** — включать только если ваш FTP-сервер требует защищённое соединение.

---

### ✅ Проверка подключения

В списке серверов у каждого сервера есть действие **«Проверить подключение»**. Оно покажет:

* есть ли доступ к FTP;
* не пустая ли корневая папка (если пустая — скорее всего, неверно указан путь до корневой папки или права FTP-пользователя);
* найдена ли папка profiles.

Если выдача товаров не работает — в первую очередь запустите эту проверку.
