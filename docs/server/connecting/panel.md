# На панели управления
Данная инструкция описывает процесс подключения магазина к серверу приобретенному на панели управления хостинга (без доступа к rdp(удаленному раб столу), когда доступ имеется непосредственно только к ftp, хостинг панели.)

---

### ⚠️ Важно перед началом

- FTP У вас уже настроен! Вам ничего не нужно скачивать, устанавливать и тд

---

### 1️⃣ Добавление сервера в магазине

Перейдите в добавление сервера и заполните поля:

- **FTP Имя пользователя** — логин FTP (предоставленный хостером)
- **FTP Порт** — `21`
- **FTP Пароль** — ранее заданный пароль (предоставленный хостером)
- **FTP Адрес** — IP сервера (без порта)
- **Путь до корневой папки** — `/`
- **Путь до папки profiles** — `profiles/`
- **FTP Pasv** — выключен!!!
- **Остальные параметры** — по желанию
