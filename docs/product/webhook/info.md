# Товары > Webhook [Post Request] > Как они работают

:::: v-pre

### ℹ️ Теоретическая часть
При покупке товара идет отправка POST Request на указанный url с заранее заданными параметрами. Данная система необходима для реализации покупок внешних товаров: для обработки различными ботами, для уведомлений в дискорд вместо покупки и прочее. Данная система поддерживает возможность передач доп параметров, которые автоматически заменяются, например: время покупки, информация о покупателе и прочее. При некорректном ответе (не 200 Success) товар является не выданным, у пользователя покупка не проходит.

---

### ⚙️ Создание товара

1. Переходим в **Управление → Товары** и нажимаем **«Создать»**.
2. Заполняем основные настройки (название, цена, категории, сервера).
3. Во вкладке **«Наполнение товара»** выбираем тип **Webhook [POST Request]**.
4. Заполняем поля:

| Поле | Описание |
|---|---|
| **Url** | Адрес, на который будет отправлен запрос. Например Discord webhook `https://discord.com/api/webhooks/...` или адрес вашего бота |
| **Заголовки** | Необязательно. Дополнительные HTTP-заголовки, например `Authorization` → `Bearer ваш_токен`. Заголовок `Content-Type: application/json` добавляется автоматически |
| **Содержание** | JSON, который будет отправлен в теле запроса. По умолчанию заполнен шаблоном под уведомление Discord |

5. Сохраняем товар.

---

### 🔤 Переменные

В поле **«Содержание»** можно использовать переменные — при покупке они автоматически заменятся на реальные значения:

| Переменная | Что подставится |
|---|---|
| `{{timestamp}}` | Текущее время в формате ISO 8601 |
| `{{product_image}}` | Ссылка на изображение товара |
| `{{product_name}}` | Название товара |
| `{{product_price}}` | Стоимость товара (с учётом скидки) |
| `{{server_name}}` | Название сервера, на котором куплен товар |
| `{{server_id}}` | ID сервера в магазине |
| `{{user_name}}` | Имя пользователя |
| `{{user_steamid}}` | SteamID пользователя |
| `{{user_id}}` | Внутренний ID пользователя в магазине |

---

### 📄 Пример: свой бот

```json
{
  "event": "purchase",
  "steam_id": "{{user_steamid}}",
  "user_id": "{{user_id}}",
  "product": "{{product_name}}",
  "price": "{{product_price}}",
  "server": "{{server_name}}",
  "time": "{{timestamp}}"
}
```

Ваш бот должен ответить кодом **2xx** (например `200 OK`). Любой другой ответ (4xx, 5xx, таймаут) считается ошибкой — покупка не пройдёт, а деньги у пользователя не спишутся.

::: warning
Если запрос к вашему серверу приходит не от магазина, его можно отсечь по IP. Список IP, с которых отправляются запросы, — на странице [Дополнительная информация](/docs/product/webhook/additional-info).
:::
