### ℹ️ Как это работает

Тип товара **«Кастомный сет от < 123new(Axel) >»** выдаёт игроку стартовый сет/скин мода CustomSpawnPlayer (автор 123new / Axel) **на время** — это аренда. При покупке магазин дописывает строку с SteamID игрока в файл `profiles/CustomSpawnPlayerConfig.txt` на сервере, а по окончании срока аренды автоматически её удаляет.

---

### ⚙️ Создание товара

1. Переходим в **Управление → Товары** и нажимаем **«Создать»**.
2. Заполняем основные настройки (название, цена, сервера).
3. Во вкладке **«Наполнение товара»** выбираем тип **«Кастомный сет от < 123new(Axel) >»** и заполняем:

| Поле | Описание |
|---|---|
| **Количество дней аренды** | На сколько дней выдаётся сет. При повторной покупке срок продлевается |
| **Скин игрока** | Класснейм персонажа, например `SurvivorM_Oliver`. `0` — без смены скина |
| **Номера сетов** | Номера сетов со стартовым лутом из конфига мода. Можно указать несколько, один или `0`, чтобы отключить опцию |
| **Spawn points** | Необязательно. Точки спавна (X, Y, Z), где будет появляться игрок |

4. Сохраняем товар.
