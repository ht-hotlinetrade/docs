# Настройка товара WARGM
---
1. Переходим в товар который мы хотим продублировать на wargm (не важно за алмазы или рубли), копируем его ид из URL (только цифры)
![](/images/product/wargm/settings/1.png)
2. Открываем раздел Объекты в магазине Wargm и добавляем новый объект с указанием ранее скопированного ID
![](/images/product/wargm/settings/2.png)
![](/images/product/wargm/settings/3.png)
3. Необходимо выбрать в поле "Доставка" - "Выдача по API", затем справа в разделе "Доступные объекты" выбрать ранее созданный объект, далее по стандарту заполняем. И готово.
При покупке товара, в течение 5-10 минут будет выдача.
