# Подключение WARGM
::: danger
**ВНИМАНИЕ! ВАЖНО!**

* Для подключения вы должны быть полным владельцем сервера/магазина на WARGM, иначе у вас не будет необходимых разделов.
:::
---
1. Необходимо перейти в раздел "API" нужного нам сервера, и нажать кнопку "Сгенерирвоать ключ" (см скрин 1)
![](/images/product/wargm/connect/first.png)
2. Далее после нажатия кнопки "Сгенерирвоать ключ" обновляем страницу и копируем из правой части (в блоке "Запросы") появившийся ключ, начиная от ид и до самого конца(Проще говоря цифры, и до самого конца). Например ```54808:POHnB0_R72_fo7vXtTU_6_VKV6kajlYR``` (см скрин 2)
![](/images/product/wargm/connect/2.png)
3. Открываем магазин (HotlineTrade) в разделе Управление -> Сервера нажимаем редактировать нужный нам сервер, далее преходим во вкладку "Параметры WARGM" и вставляем наш скопированный ранее API ключ в "API Ключ от WARGM и ID сервера"
![](/images/product/wargm/connect/3.png)
4. Копируем цифры из API ключа скопированного ранее, например ```54808``` и вставляем в "ID сервера в WARGM"
![](/images/product/wargm/connect/4.png)
6. Возвращаемся в Wargm, в настройки магазина, во вкладку API и повторяем все теже самые действия, но уже с ключем от API магазина.
![](/images/product/wargm/connect/5.png)
7. Переходим обратно в магазин(hotlinetrade) в редактирование параметров wargm у сервера, и указываем наш api ключ в "API Ключ от WARGM и ID магазина"
![](/images/product/wargm/connect/6.png)
8. Сохраняем. Мы интегрировали и сделали автовыдачу с WARGM!
ГОТОВО!
