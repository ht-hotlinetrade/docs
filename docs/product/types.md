# Товары > Создание товара и типы товаров

Товары создаются в разделе **Управление → Товары → «Создать»**. Карточка товара состоит из нескольких вкладок, ниже описано каждое поле.

---

### 1️⃣ Основные настройки

| Поле | Описание |
|---|---|
| **Название** | Название товара. Можно указать переводы для других языков сайта |
| **Цена** | Стоимость в валюте магазина |
| **Описание** | Описание товара (поддерживается Markdown) |
| **Категории** | В каких категориях отображается товар |
| **Сервера** | На каких серверах доступен товар. Если сервер не выбран — товар доступен везде |
| **Вариативные товары** | Связанные товары-варианты (например, один и тот же набор на 7 / 14 / 30 дней). Отображаются вместе на карточке |
| **Изображения** | Первое изображение в списке — основное. Максимальный вес — 2 MB |
| **Сортировка** | Позиция товара в списке (чем меньше, тем выше). Подробнее — [Смена позиции блоков](/docs/other/change-sort-order) |
| **Скрытие товара** | Товар не будет виден на главной странице, но его по-прежнему можно выдать вручную или через промокод |
| **Не отображать цену неавторизованным пользователям** | Цена и скидка будут скрыты, пока пользователь не войдёт |

---

### 2️⃣ Наполнение товара (типы)

В поле **«Тип товара»** выбирается, что именно получит игрок.

#### Товары (выдаются в корзину мода HotlineTrade)

| Тип | Что выдаёт |
|---|---|
| **Предмет** | Набор предметов: класснейм + количество. К каждому предмету можно добавить аттачменты («Прикрепляемое к предмету») и содержимое («Кладём в предмет») |
| **Транспортное средство** | Машина: класснейм корпуса, аттачменты (колёса, двери, свечи и т.д.) и содержимое багажника |
| **Телепорт** | Телепорт игрока в точку с координатами X / Y / Z |
| **Рулетка** | Случайный приз из списка товаров. У каждого приза указывается шанс в %, сумма шансов должна быть ровно 100% |

Эти товары попадают в [корзину игрока](/docs/other/view-wipe-player-cart) и забираются в игре по клавише магазина. Для них работают [зоны выдачи](/docs/product/zones/info), проверка времени жизни и повторная выдача (киты).

#### Валюта

| Тип | Что выдаёт |
|---|---|
| **Баланс в банкомат** | Деньги на счёт в моде банкомата. Поддерживаются: Banking, Advance Banking, EnhancedBanking (LB), Trader plus |
| **Расширение лимита банкомата** | Увеличение максимального лимита счёта в выбранном моде банкомата |
| **Расширение PAYDAY банкомата** | Увеличение PayDay в выбранном моде банкомата |
| **Баланс в магазин (этот)** | Пополнение баланса в самом магазине. Удобно для промокодов и рулеток |

#### Прочее

| Тип | Что выдаёт |
|---|---|
| **Приоритетный вход** | SteamID игрока записывается в `priority.txt` в корне сервера на указанное количество дней (аренда). По окончании срока автоматически удаляется |
| **Webhook [POST Request]** | Отправляет POST-запрос на ваш URL. См. [Webhook](/docs/product/webhook/info) |
| **Кастомный файл** | Изменяет любые TXT / JSON файлы на сервере по сценарию. См. [Кастомный файл](/docs/product/custom-file) |
| **Персональный ящик < SharkAttack >** | Персональный ящик мода SharkAttack: название папки и класснейм ящика |

#### Кастом (интеграции со сторонними модами, аренда на N дней)

| Тип | Мод |
|---|---|
| **Кастомный сет от < 123new(Axel) >** | См. [Подключение кастомных сетов (123new)](/docs/product/123newset-connection) |
| **Кастомный сет от < Кастет >** | Мод KTLoadout. Содержимое сета задаётся в JSON. Если включено «Использовать файл по умолчанию», за основу берётся `KTLoadoutData/Players/default.json` |
| **HH CUSTOM SET < HeadHunterz >** | Сет мода HeadHunterz, содержимое задаётся в JSON |
| **RSG BP Coin < Risage >** | Начисление BP Coin мода Risage |

### 3️⃣ Дополнительные настройки

| Поле | Описание |
|---|---|
| **Пользователи с доступом к товару** | Только эти пользователи смогут видеть и покупать товар. Пусто — доступно всем |
| **Пользователи без доступа к товару** | Эти пользователи не смогут купить товар |
| **Метки** | Цветные плашки на карточке товара («Хит», «Новинка», «-50%»). Метки создаются в **Управление → Метки товаров** или прямо из этого поля |
| **Скрытый просмотр** | Товар видят только те, у кого на балансе хватает денег. Сумму можно задать в поле «Сумма для видимости товара», иначе берётся цена товара |
| **Ограничение на покупку одним пользователем** | Не более N покупок одним игроком за период (в минутах) |
| **Ограничение на покупку всеми пользователями** | Не более N покупок всеми игроками вместе за период. Удобно для «лимитированных» товаров |

#### Повторная выдача товара (КИТЫ aka. СТРАХОВКА)

Доступно для товаров, которые попадают в корзину (предметы, транспорт, телепорты). Позволяет игроку забирать один и тот же купленный товар несколько раз.

| Поле | Описание |
|---|---|
| **Включить повторную выдачу** | Включает механику китов |
| **Задержка между выдачами** | Через сколько минут после последнего получения товар снова станет доступен |
| **Максимум повторных выдач** | Сколько раз можно забрать товар повторно. Пусто — без ограничений |
| **Срок действия для выдачи** | Сколько минут после покупки товар можно забирать. Пусто — бессрочно |
| **Разрешить 1 получение после окончания срока** | Если игрок ни разу не забрал товар до окончания срока — он всё равно сможет получить его один раз |

---

### 4️⃣ Доступ к выдаче

| Поле | Описание |
|---|---|
| **Зоны выдачи** | Где можно забрать товар из корзины. См. [Зоны выдачи](/docs/product/zones/info) |
| **Включить проверку на время жизни** | Товар можно забрать только спустя N секунд после смерти/спавна игрока |

---

### 🎁 Ручная выдача товара

Товар можно выдать игроку бесплатно — например, в качестве компенсации:

1. Откройте **Управление → Пользователи** и найдите игрока.
2. Нажмите действие **«Выдать товар»**.
3. Выберите **Сервер**, затем один или несколько **Товаров**.
4. Подтвердите выдачу.

Выдача попадает в уведомления с типом «Выдача администратором». Если покупка в истории (**История → Покупки**) по какой-то причине не дошла до игрока, её можно выдать заново действием **«Повторно выдать»**.

---

### 🧰 Массовые действия со списком товаров

В списке товаров отметьте нужные товары галочками — станут доступны действия:

| Действие | Что делает |
|---|---|
| **Изменить цену** | Установить цену, повысить/снизить на сумму или на % |
| **Изменить видимость** | Скрыть или показать выбранные товары |
| **Изменить серверы** | Заменить, добавить или удалить серверы у выбранных товаров |
| **Копировать** | Создать копии товаров вместе с наполнением |

::: info
Товар, который используется в планировщике аренды, удалить нельзя — сначала остановите связанные аренды.
:::
