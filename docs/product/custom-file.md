# Товары > Кастомный файл

:::: v-pre

::: danger
**ВНИМАНИЕ!** Этот тип товара изменяет файлы прямо на вашем игровом сервере. Ошибка в сценарии может сломать конфиг мода или сервер. Перед использованием на живом сервере проверьте сценарий на тестовом и сделайте резервную копию файлов.
:::

### ℹ️ Что это такое

**Кастомный файл** позволяет выдавать почти любые «нестандартные» товары: VIP-статусы, вайтлисты, права в модах, доступ к функциям и т.д. — всё, что сводится к правке TXT или JSON файла на сервере. При покупке магазин подключается к серверу по FTP и выполняет ваш сценарий (payload).

---

### ⚙️ Создание товара

1. **Управление → Товары → «Создать»**, заполняем основные настройки.
2. Во вкладке **«Наполнение товара»** выбираем тип **«Кастомный файл»**.
3. В поле **«Пример / шаблон payload»** можно выбрать готовый пример — он подставится в редактор. Примеры показывают формат, а не готовые решения: пути и ключи нужно поменять под ваш мод.
4. Пишем сценарий в поле **«Payload (JSON сценарий)»** и сохраняем.

---

### 📐 Структура payload

```json
{
  "files": [
    {
      "path": "MyMod/Config",
      "name": "vip.txt",
      "type": "txt",
      "actions": [
        { "type": "append", "lines": ["{{steam_id}}"] }
      ]
    }
  ]
}
```

| Ключ | Описание |
|---|---|
| `files` | Список файлов, которые нужно изменить. Можно указать несколько |
| `path` | Путь до папки **относительно папки profiles** сервера. Пустая строка `""` — сама папка profiles |
| `name` | Имя файла |
| `type` | Тип файла: `txt` или `json` |
| `actions` | Список действий над файлом, выполняются по порядку |

Итоговый путь к файлу: `{Путь до корневой папки}/{Путь до папки profiles}/{path}/{name}` — берётся из настроек сервера. Если файла нет, он будет создан.

---

### 🔤 Переменные и формулы

| Переменная | Значение |
|---|---|
| `{{steam_id}}` | SteamID покупателя |
| `{{user_id}}` | ID пользователя в магазине |
| `{{server_id}}` | ID сервера в магазине |
| `{{server_name}}` | Название сервера |
| `{{product_name}}` | Название товара |
| `{{now}}` | Текущее время (Unix timestamp, в секундах) |

Поддерживаются простые формулы: `{{ now + 3600 }}` — через час, `{{ now + 86400 }}` — через сутки, `{{ now - 60 }}` — минуту назад.

---

### 📝 Действия для TXT

| Действие | Описание |
|---|---|
| `append` | Добавляет строки из `lines` в конец файла. Строки, которые уже есть в файле, повторно не добавляются |
| `remove` | Удаляет строки из `lines` |
| `create` / `update` | Полностью перезаписывает файл строками из `lines` |

### 🧾 Действия для JSON

| Действие | Описание |
|---|---|
| `merge` | Записывает значения из `data`. Ключи можно указывать через точку: `"users.{{steam_id}}.role": "vip"` создаст вложенные объекты |
| `merge_array` | Добавляет `value` в массив по ключу `key`, если такого значения там ещё нет |
| `remove` | Удаляет ключи из `keys` (поддерживается путь через точку) |
| `rewrite` | Полностью заменяет содержимое файла на `data` |

### ❓ Условия

Любое действие можно выполнить только при выполнении условия: `if` — условие, `then` — действие.

| Условие | Тип файла | Когда выполняется |
|---|---|---|
| `"not_contains": "текст"` | TXT | В файле нет указанного текста |
| `"not_exists_in_array": "Ключ", "value": "..."` | JSON | В массиве по ключу нет указанного значения |
| `"always": true` | любой | Всегда |

### 📄 Примеры

**Добавить SteamID в TXT, если его там ещё нет**
```json
{
  "files": [
    {
      "path": "HotlineTrade/profiles",
      "name": "vip.txt",
      "type": "txt",
      "actions": [
        {
          "type": "conditional",
          "if": { "not_contains": "{{steam_id}}" },
          "then": { "type": "append", "lines": ["{{steam_id}}"] }
        }
      ]
    }
  ]
}
```

**Выдать VIP в JSON со сроком действия 1 сутки**
```json
{
  "files": [
    {
      "path": "config",
      "name": "users.json",
      "type": "json",
      "actions": [
        {
          "type": "merge",
          "data": {
            "users.{{steam_id}}": {
              "role": "vip",
              "expires": "{{ now + 86400 }}"
            }
          }
        }
      ]
    }
  ]
}
```

**Добавить SteamID в массив WhiteList**
```json
{
  "files": [
    {
      "path": "MyMod",
      "name": "config.json",
      "type": "json",
      "actions": [
        {
          "type": "conditional",
          "if": { "not_exists_in_array": "WhiteList", "value": "{{steam_id}}" },
          "then": { "type": "merge_array", "key": "WhiteList", "value": "{{steam_id}}" }
        }
      ]
    }
  ]
}
```

::: warning
Многие моды читают конфиг только при запуске сервера. Если мод не подхватывает изменения на лету — выданный товар начнёт работать после рестарта.
:::
