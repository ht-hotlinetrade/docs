# Прочее > Перевод средств между игроками

### ℹ️ Что это такое

Игроки могут переводить деньги со своего баланса другим игрокам (раздел «Перевод» в профиле). Функция выключена по умолчанию.

---

### ⚙️ Настройка

**Управление → Настройки → Перевод средств**

| Поле | Описание |
|---|---|
| **Состояние (вкл/выкл)** | Включает переводы |
| **Комиссия** | Процент, который **дополнительно** списывается с отправителя. Например, при комиссии 5% перевод 100 ₽ спишет с отправителя 105 ₽, а получатель получит 100 ₽ |
| **Мин. кол-во дней с момента регистрации** | Переводить могут только аккаунты старше N дней |
| **Мин. кол-во покупок** | Переводить могут только игроки, совершившие не меньше N покупок |
| **Мин. сумма перевода** / **Макс. сумма перевода** | Границы суммы одного перевода |
| **Разрешенное кол-во переводов в мес** | Лимит переводов одного игрока в месяц |
| **Пользователи с доступом к переводу** | Если заполнено — переводить могут только эти пользователи. Пусто — все, кто проходит условия выше |

::: tip
Ограничения по возрасту аккаунта и количеству покупок защищают от абуза стартового баланса и бонусов через «твинков».
:::

---

### 📊 История

Все переводы — в разделе **История → Переводы**. Можно подключить [уведомления](/docs/other/notifications) с типом «Перевод».
