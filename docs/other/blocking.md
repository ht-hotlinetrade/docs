# Прочее > Блокировка

::: info
Блокировка возможна только на IP или конкретного пользователя. Доступ ограничивается непосредственно на сайте, при ограничение на IP, доступ к API не блокируется (у ап свои вайтлисты)!
:::

**Блокировка:**
1. Переходим в раздел "Управление -> Блокировки", нажимаем кнопку "создать" в вверхнем правом угле.
2. На появившейся странице выбираем тип блокировки (IP, Пользователь), заполняем все необходимые данные и нажимаем создать.

**Разблокировка:**
2 способа:
- Можно в списке заблокированных пользователей нажать клавишу "Разбанить", блокировка будет снята, но она останется в истории банов с датами, коментами и тд, и будет участвовать в системе.
- Можно удалить из списка, тогда про эту блокировку система просто "забудет".
---

**Поля блокировки:**

| Поле | Описание |
|---|---|
| **Тип блокировки** | **Пользователь** — блокируется конкретный аккаунт. **IP-адрес** — блокируется доступ к сайту с этого IP для всех |
| **Комментарий / причина** | Причина блокировки (для истории) |
| **Действует до** | Дата окончания. Оставьте пустым — блокировка навсегда |

Статусы блокировок: **Активен**, **Истёк** (срок закончился), **Снят** (разбанен вручную).

::: warning
Нельзя заблокировать собственный IP — это защита от случайной потери доступа к админке.
:::

---

### 🔎 Поиск по IP-адресу

Чтобы найти «твинков» или понять, с какого IP заходил нарушитель, используйте **Инструменты → Поиск по IP-адресу**. Можно ввести полный IP, его часть или маску подсети (например `127.0.0.0/24`) — инструмент покажет всех пользователей, которые заходили с этих адресов.
