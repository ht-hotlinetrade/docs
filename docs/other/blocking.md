# Прочее > Блокировка

::: info
Блокировка возможна только на IP или конкретного пользователя. Доступ ограничивается непосредственно на сайте, при ограничение на IP, доступ к API не блокируется (у ап свои вайтлисты)!
:::

**Блокировка:**
1. Переходим в раздел "Управление -> Блокировки", нажимаем кнопку "создать" в вверхнем правом угле.
2. На появившейся странице выбираем тип блокировки (IP, Пользователь), заполняем все необходимые данные и нажимаем создать.

**Разблокировка:**
2 способа:
- Можно в списке заблокированных пользователей нажать клавишу "Разбанить", блокировка будет снята, но она останется в истории банов с датами, коментами и тд, и будет участвовать в системе.
- Можно удалить из списка, тогда про эту блокировку система просто "забудет".
